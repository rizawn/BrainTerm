# Known Limitations

This document records verified technical boundaries and unverified areas in the current BrainTerm codebase (`0.1.0` pre-beta).

## 1. Licensing & Distribution

- **No root `LICENSE` file:** As noted in [README.md](../README.md), the repository does not yet contain a top-level `LICENSE` file; original source code rights remain reserved by the author until a license is selected. Bundled fonts (`OFL-1.1`) and transitive runtime libraries have individual licenses documented in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
- **No code signing yet:** Portable Windows builds generated by `scripts/package-win.ps1` are unsigned and may trigger Windows SmartScreen prompts when downloaded from the internet.

## 2. Platform & Interactive Verification Coverage

- **Linux desktop UI not interactively tested here:** `pty_unix.c` and Ubuntu builds are verified by compilation and automated tests under `xvfb-run` in `.github/workflows/ci.yml`, but interactive GTK4/OpenGL rendering and `forkpty` TUI sessions have not been manually tested in a live human Linux desktop session in this cycle.
- **Windows IME & live TUI stress unverified interactively:** Automated VT corpus tests verify `libvterm` sequence parsing (`test_vtcorpus`), and ConPTY child lifecycle tests pass (`test_tabs`, `test_pty_cleanup`), but CJK/dead-key IME composition and manual drag-resizing of full-screen TUIs (`vim`, `htop`, `claude`) require human interactive verification.
- **Sanitizer builds unavailable on MSYS2 UCRT64 GCC 16.1.0:** Compiler probes for `-fsanitize=address` and `-fsanitize=undefined` fail at link time on this Windows toolchain (`cannot find -lasan` / `cannot find -lubsan`), leaving ASan/UBSan runtime runs unverified locally.
- **macOS unsupported:** No Cocoa/macOS build configuration or packaging target exists (`meson.build` targets Windows and Linux).

## 3. Functional Scope Boundaries

- **Offline embeddings use lexical token vectors (`src/embed.c`):** The built-in embedding engine hashes lowercased ASCII tokens into normalized 128-dimensional signed FNV-1a word and character-trigram feature vectors (guarded against non-finite floats) for offline cosine/RRF hybrid search without network calls or model weights. It improves token-overlap robustness and query matching alongside FTS5, rather than providing deep neural synonym embeddings.
- **Auto-organizer local-model backend (`BT_ORG_LOCAL_MODEL`):** The default `BT_ORG_NO_AI` heuristic engine and fixed-argv CLI backend (`BT_ORG_CLI`) are active, while `BT_ORG_LOCAL_MODEL` invokes a caller-supplied callback hook and does not ship an embedded LLM runtime.
- **Logseq parity specification unimplemented:** Phases `P1–P9` in [logseq-parity.md](logseq-parity.md) (`tasks.c`, `query.c`, global link-rewriting `rename.c`, HTML/PDF `exporter.c`, migrations `0003..0006`) remain design specs and are not implemented in `src/`.
- **Starter Vault empty-folder note counts:** Newly created starter vaults rely on `vault-template/` (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `examples/links-demo.md`). Non-empty pre-existing target directories refuse starter vault overwrite (`BT_ERROR_INVALID`).
- **MCP server (`bt-mcp`) scope:** `bt-mcp` opens `vault/.bt/index.db` strictly read-only. It reflects the latest indexed vault state and does not read unsaved in-memory editor buffers or support write tools (write tool calls are intentionally rejected).
- **Split-view Brain Graph toolbar width:** When Brain Graph is docked beside the editor in a narrow horizontal split (`~400 px`), the top-left overlay pill toolbar can visually crowd against top-right controls; resizing the splitter wider or hiding the editor maximizes toolbar clarity.
