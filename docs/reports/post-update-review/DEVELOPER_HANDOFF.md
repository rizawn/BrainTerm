## 2. Reproducible Build, Test & Packaging Playbook

### Windows 11 (`MSYS2 UCRT64` + PowerShell)
Running `.exe` processes lock build/package outputs on Windows; terminate active binaries before rebuilding or packaging:

```powershell
# 1. Stop active binaries and prepend MSYS2 UCRT64 toolchain
taskkill /IM bt.exe /F 2>$null
taskkill /IM bt-mcp.exe /F 2>$null
$env:PATH = "C:\msys64\ucrt64\bin;$env:PATH"

# 2. Configure (clean clone only) and build with -Dwerror=true
meson setup build -Dwerror=true
meson compile -C build

# 3. Execute all 30 correctness suites sequentially (-j 1 required for GTK4/GL)
meson test -C build --suite unit --suite crash-rig --suite vtcorpus --print-errorlogs -j 1

# 4. Execute all 7 performance benchmarks sequentially
meson test -C build --suite bench --print-errorlogs -j 1

# 5. Headless CLI verification
.\build\src\bt.exe --version
.\build\src\bt.exe --selftest-links vault-template

# 6. Build portable bundle + isolated System32-only PATH smoke verification
powershell -ExecutionPolicy Bypass -File scripts/package-win.ps1 -KillRunning -BuildDir build -OutDir dist\brainterm -SmokeTest
```

- **Expected Pass Criteria:** `30 / 30` correctness targets (`144` cases) OK, `7 / 7` benchmarks OK, `BT_SMOKE ok ...`, and `BT_MCP_SMOKE ok readOnly=true`.
- **Why `-j 1` Serialization Is Mandatory:** `editor_links`, `fix_ui`, `math_highlight`, `theme`, `bench_graph_1k`, and `bench_graph_gl` realize real GTK4/GL windows or mutate temporary `BT_CONFIG_DIR` dirs; parallel runs trigger window-focus and GPU races.

### Linux (`Ubuntu / Debian` Matching `.github/workflows/ci.yml`)
Mirrors `.github/workflows/ci.yml` (`ubuntu` job using Xvfb):

```bash
meson setup build -Dwerror=true
meson compile -C build
xvfb-run -a meson test -C build -j 1 --print-errorlogs
```

### Safe Manual QA Sandbox Rule
Never point manual QA binaries at personal vaults or default `%LOCALAPPDATA%` state: isolate config via `BT_CONFIG_DIR` and pass a scratch copy of `vault-template` via `--vault`.

## 3. Non-Negotiable Architectural Invariants ([docs/DECISIONS.md](../../DECISIONS.md))

1. **Compile-Time Layering (`ADR-001`, `ADR-008`, `ADR-019`):** Keep `libbt_core.a` (`src/*.c`) completely free of `<gtk/gtk.h>`, `<cairo.h>`, and `<epoxy/gl.h>`; keep `src/math/*` limited to GLib/GIO/HarfBuzz/`-lm`.
2. **L0 Plain-Markdown Authority (`ADR-003`, `P1–P7`):** Never store user knowledge solely inside `.bt/index.db`. `bt_index_rebuild()` + `bt_index_dump_canonical()` must reconstruct SQLite deterministically from `.md` files alone.
3. **Single SQLite Writer Thread (`ADR-007`):** Only `bt-db-writer` (`src/index.c`) touches `sqlite3 *` in the GUI process; route new DB reads/writes through synchronous `GAsyncQueue` requests.
4. **Canonical Path Containment (`vault_resolve()`):** All vault reads, writes, renames, deletes, importer outputs, terminal `cwd` values, and MCP reads must validate canonical bounds through `vault_resolve()`.
5. **Create-Only Note Semantics (`ADR-023`):** `bt_createnote_commit()` uses OS non-overwriting primitives (`MoveFileExW` without replace / POSIX `link`+`unlink`); never replace it with `vault_atomic_write()`.
6. **Human Tag Locks & YAML/Git Safety (`ADR-024`, `P4`, `R9`, `R10`):** Ambiguity chooser copies explicit `[[folder/name]]` without editing prose; promoted/dismissed tags lock permanently; malformed YAML (`R9`) and locked `.git/index.lock` (`R10`) abort writes cleanly.
7. **Dusk Token Parity & Toolkit API Floor:** Keep `data/theme.css` synchronized 1:1 with `src/theme.h` (`test_theme` validates hex parity + WCAG AA contrast). Use `gtk4 >= 4.10` / `libadwaita >= 1.4` APIs cleanly (avoid `AdwDialog` 1.5+ and deprecated GTK 4.18 shortcut window classes).

1. **Choose & Commit Root `LICENSE`:** Select compatible open-source licensing (`README.md`, `THIRD_PARTY_LICENSES.md`) prior to external binary distribution.
2. **Sync Verified Work & Validate GitHub CI:** Push curated commits to `origin/master`, confirm green `windows` and `ubuntu` (`xvfb-run`) runs in `.github/workflows/ci.yml`, and test Linux ASan/UBSan (`-Db_sanitize=address,undefined`).

4. **Ship Signed Installers & Linux Packages:** Build signed Windows ZIP/Inno Setup installers and Linux AppImage/Flatpak packages (`docs/ROADMAP.md`).
5. **Scope `v0.3.0` Enhancements:** Evaluate selective Logseq outliner/task/export items (`docs/logseq-parity.md`) and optional local neural embedding backends behind `bt_embed_*`.

### Quick Maintainer Troubleshooting Reference
- **Windows Linker `Permission denied` During Rebuild:** Running `bt.exe` or `bt-mcp.exe` holds file locks; run `taskkill /IM bt.exe /F` and `taskkill /IM bt-mcp.exe /F` (or `scripts/package-win.ps1 -KillRunning`).
- **Headless Test Flakiness Under Parallel Jobs:** Always pass `-j 1` to `meson test` so GTK4 focus checks and OpenGL suites (`editor_links`, `fix_ui`, `theme`, `bench_graph_*`) run sequentially.
- **Rendering Without Hardware OpenGL:** Set `BRAINTERM_GRAPH_BACKEND=cairo` to test software Graph rendering cleanly across CI/VMs.
